# M3S Custom Swarm DSL Vocabulary Spec
# Format: ID TOKEN DESCRIPTION

# 0-3: Special Tokens
0 <PAD> Padding token
1 <UNK> Unknown token
2 <BOS> Beginning of Sequence
3 <EOS> End of Sequence / Turn delimiter

# Core Protocol Delimiters & Routing
4 SIT: Situational context marker
5 ACT: Action protocol marker
6 THK: Internal reasoning / Chain-of-Thought marker
7 : Field separator
8 | Command separator
9 -> Vector direction / target arrow
10 , Multi-entity separator
11 _ Token compound connector
